agentic-trader

A multi-agent LLM trading framework for equities and FX, modelled on a real trading desk. An analyst team (technical, fundamentals or macro/rates, news, sentiment) writes structured reports; bull and bear researchers debate them under a facilitator; a trader sizes the trade around a strategic weight; aggressive, neutral and conservative risk analysts argue the size; a portfolio manager decides — inside hard limits no model output can override. Every number comes from a C++17 quant core; Claude writes the reasoning. Evaluated on real prices with a design / holdout split. Inspired by the TradingAgents paper, written from scratch. Python · C++17 · pybind11 · Claude (Anthropic SDK) · FRED · walk-forward backtesting.

The agents do not beat buy & hold on risk-adjusted returns out of sample — and the page says so. On the 2022–26 holdout the rule-based firm's mean Sharpe per instrument is 0.44 against 0.55 for buy & hold; what it reliably delivers is about half the drawdown in every period, and as a diversified portfolio it edges plain buy & hold (1.14 vs 1.06) but not buy & hold scaled to the same volatility (1.24). The v0.3 rule changes were picked on 2016–21 data only; their Sharpe gain there (0.76 → 0.99 in equities) mostly did not survive the holdout, their return and turnover gains did. Most literature-backed signal tweaks (time-series momentum, trend-filtered reversals, abstention) measured as noise and stay off. The LLM mode has not been evaluated, so none of the paper's LLM results are claimed.

What's inside

Analyst team

Technical (SMA 20/50/200, MACD, RSI, Bollinger %B, KDJ, ATR, momentum), Fundamentals for equities, News (recency-weighted headline tone) and Sentiment (social posts plus crowding proxies). Each returns signal, confidence, key points — or abstains when it has no data, and then makes no LLM call.

FX macro analyst

Carry from the policy-rate differential, inflation (PPP) and distance from the 200-day average — fed by point-in-time FRED rates: daily series lagged a day, monthly averages ~40 days, stale series treated as missing instead of carried forward for years.

Bull / bear debate

Two deep-tier researchers argue for n rounds, citing the strongest supporting reports and rebutting the other side; a facilitator records winner, signed score and conviction as structured data for the trader.

Strategic weight + tilt

The trader holds a benchmark weight when it has no view (equities fully invested, FX flat) and tilts with conviction — how real mandates work, and the one v0.3 change that moved design-period results. Stops and targets at ATR multiples, sanity-checked.

Risk team & portfolio manager

Aggressive, neutral (vol-targeted) and conservative (VaR-capped) views, blended 25/50/25; then firm limits run in code: max position, 1-day VaR95, shorting, minimum trade, and a no-trade band that keeps the current position only if it is still legal.

Portfolio context

propagate(..., current_weight=) tells the firm what it holds. The trader and PM see it; the band avoids paying spread for trivial changes (−44% trades at equal Sharpe on design data).

Prompt-injection containment

Third-party text reaches the model only inside <untrusted_data> blocks whose tags cannot be closed from inside; model output is clipped and every limit runs afterwards. Tests feed injected headlines and hijacked replies and check nothing leaks or breaches.

LLM cost control

Two model tiers (Haiku 4.5 analysts, Opus 5 with adaptive thinking for reasoning), request timeouts, typed SDK error handling, server-side refusal fallback, and an optional hard call budget after which agents fall back to rules.

C++17 quant core

Indicators, risk and baselines, plus a backtester with costs, per-bar carry, borrow, leverage caps and intraday stop/target fills (level, or the open on a gap; stop first if both trade). Sharpe t-stat and exposure in every result.

numpy reference twin

A line-for-line numpy implementation used automatically without a compiler. CI asserts the active backend; randomised tests cross-check the extended backtester (stops, gaps, carry, re-arming, shorts) between the two to 1e-11.

Evaluation harness

evaluate() runs a universe over named periods and reports per-instrument and aggregate results, head-to-head counts and failures. Design / holdout / paper-window protocol, 16-variant ablation, everything reproducible from the CLI.

Fair baselines

The paper's five (Buy & Hold, SMA, MACD, KDJ+RSI, ZMR) plus buy & hold scaled to the same volatility target from trailing vol — the control that separates "held less" from "called direction well".

Watchlists & portfolios

scan decides a whole watchlist with current positions and exports CSV/JSON (one bad ticker becomes an error row, not a crash); portfolio runs equal-capital multi-asset sleeves across equity and FX calendars.

Edge cases handled

Messy CSVs (unsorted, duplicate dates, blank closes, impossible bars), weekends and holidays, stale or ended feeds, mistyped pairs, flat prices, NaN weights, corrupt memory logs, out-of-range or non-numeric model output — each with a test.

Decision memory

Decisions are logged atomically; once their horizon passes, realised P&L and a lesson feed later runs with a hit-rate track record. Outcomes resolve only with prices known at the current date.

Offline by default

No API key, no network: deterministic rule-based agents on synthetic data run the whole pipeline, tests and backtests out of the box. --data yahoo --llm anthropic switches to real data and Claude.

Quick start

git clone https://github.com/AshJha0/agentic-trader && cd agentic-trader
python -m venv .venv && source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[all]"

# one decision, offline: synthetic data, rule-based agents, no API key
agentic-trader analyze EURUSD --date 2024-03-01

# a watchlist, a backtest, a multi-asset portfolio
agentic-trader scan AAPL,MSFT,EURUSD --date 2024-03-01 --out decisions.csv
agentic-trader backtest AAPL --start 2024-01-02 --end 2024-03-28
agentic-trader portfolio AAPL,MSFT,EURUSD --start 2023-01-02 --end 2023-12-29

# the evaluation on real prices (design / holdout / paper window)
agentic-trader evaluate --data yahoo --periods design,holdout,paper

# optional: build the C++ core (CMake + a C++17 compiler), then the suites
./scripts/build_cpp.sh            # Windows: scripts\build_cpp.ps1
pytest && ctest --test-dir build -C Release

# live: Claude + real prices (export ANTHROPIC_API_KEY=... or `ant auth login`)
agentic-trader analyze MSFT --llm anthropic --data yahoo --max-llm-calls 50
