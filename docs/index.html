agentic-trader

A multi-agent LLM trading framework for equities and FX, modelled on a real trading desk. An analyst team (technical, fundamentals or macro/rates, news, sentiment) writes structured reports; bull and bear researchers debate them under a facilitator; a trader sizes the trade; aggressive, neutral and conservative risk analysts argue the size; a portfolio manager decides — inside hard limits no model output can override. Every number comes from a C++17 quant core; Claude writes the reasoning. Inspired by the TradingAgents paper, written from scratch. Python · C++17 · pybind11 · Claude (Anthropic SDK) · walk-forward backtesting.

The LLM reasons; the numbers and the limits come from deterministic code. Every agent computes its facts with tools first (the C++ core), forms a transparent rule-based judgement, and only then asks Claude — whose JSON is clipped to valid ranges and replaced by the rule-based result on any error, refusal or unparsable reply. After the portfolio manager decides, hard limits run in code: position cap, 1-day VaR95 cap, shorting policy, minimum trade size; a test drives a model that tries to short an equity and checks it is forced flat. The results above were produced by the rule-based agents; the LLM mode has not been evaluated, so none of the paper's LLM results are claimed here. On real Q1 2024 prices the rules-only firm cut drawdown but lagged buy-and-hold in a strong rally — reported, not tuned away.

The architectural boundary

LLM (Claude)reasoning, debate, narrative — returns structured JSON, never computes a metric
C++ quant coreindicators, VaR/CVaR, sizing, backtests — numpy twin for portability
Data providerspoint-in-time only: nothing after the as-of close reaches an agent
Rule-based agentsthe transparent baseline and the fallback for every LLM call
Portfolio manager limitsauthority: size, VaR, shorting, min trade — enforced after the model
Memoryoutcomes resolve only after their horizon — reflection without look-ahead

What's inside

Analyst team

Technical (SMA 20/50/200, MACD, RSI, Bollinger %B, KDJ, ATR, vol-adjusted momentum), Fundamentals for equities (P/E vs sector, growth, margins, leverage, FCF yield, EPS surprise, insiders), News (recency-weighted headline tone) and Sentiment (social posts plus contrarian crowding proxies). Each returns signal, confidence, summary and key points.

FX macro analyst

Replaces company fundamentals for currency pairs: policy-rate differential (carry), inflation differential (PPP drag) and distance from the 200-day average. Rates come from config or FRED; FX headlines are scored from the base currency's point of view, so "JPY weakens" is bullish USD/JPY.

Bull / bear debate

Two deep-tier researchers argue for n rounds, each citing the strongest supporting reports and rebutting the other side's latest turn. A facilitator records the verdict — winner, signed score, conviction, summary — as structured data for the trader.

Trader

Turns the verdict into a proposal: action, signed target weight, stop-loss and take-profit at ATR multiples, holding horizon. Sizes down automatically when the instrument's recent track record from memory is poor.

Risk team & portfolio manager

Aggressive, neutral (volatility-targeted) and conservative (VaR-capped) analysts debate the size over m rounds. The PM blends their views 25/50/25 (or takes Claude's call), then firm limits apply: max position, 1-day VaR95 cap, shorting policy, minimum trade size.

Structured global state

Agents write typed documents — AnalystReport, DebateOutcome, TradeProposal, RiskView, FinalDecision — into one TradingState instead of a growing chat history, avoiding the paper's "telephone effect". to_markdown() renders the full audit trail of any decision.

Two model tiers

Quick tier (claude-haiku-4-5) for analysts summarising tool output; deep tier (claude-opus-5, adaptive thinking, configurable effort) for everything that reasons. Server-side refusal fallback on by default; typed SDK error handling.

C++17 quant core

SMA, EMA, rolling std, z-score, Wilder RSI, MACD, Bollinger, ATR, KDJ, returns, realised vol; historical VaR/CVaR, Kelly, vol-target weights, stop-based units; a vectorised backtester with costs, slippage, FX carry, equity borrow and leverage caps; exposed via pybind11.

numpy reference twin

A line-for-line numpy implementation of the core. The package uses C++ when the extension is built and falls back transparently otherwise; CI asserts which backend is active and cross-checks every indicator, strategy and backtest between the two.

Paper baselines

Buy & Hold, MACD, KDJ+RSI, ZMR (z-score mean reversion) and SMA crossover — the strategies the TradingAgents paper compares against — implemented in C++ and run on the same window and cost model as the agent firm.

Walk-forward backtester

Runs the complete agent graph at every rebalance date with data up to that close, holds the decision to the next rebalance, and reports CR, AR, volatility, Sharpe, Sortino, max drawdown, Calmar, win rate and trades against all baselines.

Point-in-time data

Synthetic (seeded, regime-switching, fat-tailed prices with news, social posts and lagged quarterly fundamentals), Yahoo Finance + FRED, and CSV providers. Yahoo's current-snapshot fundamentals are refused for past dates rather than leaked.

Decision memory

Every decision is logged; once its horizon passes, the realised P&L and a lesson are attached and fed to later runs on the same instrument, together with a hit-rate track record. Outcomes are resolved only with prices known at the current as-of date.

Offline by default

No API key, no network: every agent's rule-based reasoning runs deterministically on synthetic data, so the whole pipeline, the tests and the backtests work out of the box. Switch on Claude and real data with two flags.

CLI & examples

agentic-trader analyze · backtest · baselines · info, plus a standalone C++ at_backtest for any OHLC CSV, and runnable equity, FX and baseline-comparison examples.

CI on three platforms

GitHub Actions builds the C++ core with GCC, MSVC and Clang, runs ctest and pytest on the C++ backend, and runs the Python suite on five Python versions without a compiler.

Quick start

git clone https://github.com/AshJha0/agentic-trader && cd agentic-trader
python -m venv .venv && source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[all]"

# one decision, offline: synthetic data, rule-based agents, no API key
agentic-trader analyze EURUSD --date 2024-03-01

# walk-forward backtest against the paper's five baselines
agentic-trader backtest AAPL --start 2024-01-02 --end 2024-03-29 --every 5

# optional: build the C++ core (CMake + a C++17 compiler)
./scripts/build_cpp.sh            # Windows: scripts\build_cpp.ps1

# the suites: pytest (Python) and ctest (C++)
pytest && ctest --test-dir build -C Release

# live: Claude + real prices (export ANTHROPIC_API_KEY=... or `ant auth login`)
agentic-trader analyze MSFT --llm anthropic --data yahoo
